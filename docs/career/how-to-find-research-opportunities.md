如何寻找并争取学术研究机会？

对于缺乏人脉或资源的本科生及转专业同学，获得第一段扎实的研究经历往往是最艰难的一步。  
分享如何打破僵局、敲开实验室大门。🧵

---

### 1. 从“贡献价值”切入，而非索取资源 (Lead with value)

❌ “我想加入您的课题组学习，希望能得到您的指导，我想发表论文……”  
✅ “我复现了您课题组上个月发布的开源项目，发现当前在极端光照下跟踪会漂移。我实现了一个简单的卡尔曼滤波修补补丁（附 GitHub PR 链接），希望能探讨是否有机会在这个方向上做更深入的研究。”

---

### 2. 展现你扎实的基础工程与落地能力 (Demonstrate technical skills)

教授最看重的是学生是否具备靠谱的执行力。  
提供可公开查看的 GitHub 代码仓库、整洁的复现报告，远比口头说“我数学很好”更有说服力。

---

### 3. 尊重教授的时间，做好长线跟进

如果邮件一周没有收到回复，礼貌发送一条简短的 Follow-up。如果依然没有回复，不要气馁，继续打磨自己的技能包。
