How to improve asynchronous communication? 

Two years into remote work, asynchronous communication has never been this important for work efficiency and productivity. 

Some tips for effective async communication 🧵

如何提升异步沟通效率？

进入远程办公时代以来，异步沟通对于工作效率和生产力而言从未像现在这样至关重要。

分享一些行之有效的异步沟通技巧。🧵

---

*Self-contained messages*  
Always provide the necessary context, links, and screenshots in one message so the reader doesn't need to ping back to ask for details.

*自成一体的消息 (Self-contained messages)*  
始终在一条消息中附带完整的上下文、相关链接与截图，让接收者无需来回询问即可掌握全貌。

---

*Screen recordings for complex issues*  
Record a 1-2 minute Loom video instead of typing paragraphs when explaining dynamic visual results or software bugs.

*复杂问题善用短视频录屏 (Screen recordings for complex issues)*  
当需要解释复杂的动态视觉效果或软件 Bug 时，录制一段 1-2 分钟的短视频，效率胜过敲打几百字文本。

---

*Respect deep work*  
Don't expect immediate replies. Give collaborators dedicated blocks of focus time.

*尊重深度专注时间 (Respect deep work)*  
不要期望对方秒回。给合作者留出不受打扰的整块深度专注时间。
