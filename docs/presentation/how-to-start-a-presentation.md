# 如何开启一场精彩的学术演讲？ (How to start a presentation?)

> 原始推文：[https://twitter.com/jbhuang0604/status/1548882661581754370](https://twitter.com/jbhuang0604/status/1548882661581754370)

如何开启一场精彩的学术演讲？

演讲的前两分钟决定了听众是聚精会神还是低头看手机。  
分享如何开场的关键策略。🧵

---

### 1. 避免冗长无聊的自我介绍与套话

不要花费一分半钟重复念幻灯片上的题目、单位和冗长的目录页。  
直入主题，迅速抓住听众的好奇心。

---

### 2. 用一个引人入胜的故事或现实痛点开场 (Hook the audience)

展示一个令人惊讶的真实案例、一个违背直觉的实验现象，或者一个每个人都曾经历过的痛点。  
让听众从第一秒就建立共情：“这个问题太有趣了，我也想知道答案”。

---

### 3. 清晰阐述核心主旨 (Core takeaway upfront)

不要把最重要的成果藏在第 25 页幻灯片最后。  
在开场就用一句话点明本文的核心突破：“今天我要向大家展示的是，我们如何仅用单张普通图像实现实时的三维场景重建”。
