# 如何开启一场学术演讲？ (How to start a presentation?)

如何开启一场学术演讲？

绝大多数人一开场就汇报所有枯燥乏味的信息（例如重复念一遍标题、作者列表、单位致谢和目录大纲）🥱。

相反，在头两分钟内，你应该**牢牢抓住听众的注意力（HOOK the audience）**！

分享一些我认为很有用的开场技巧。🧵

---

### 用引人入胜的谜题或真实痛点开场 (Start with a puzzle or hook)

展示一个违背直觉的实验现象、一个震撼人心的视觉对比，或者一个引发全场共鸣的现实难题。

---

### 避免念经式的目录页 (Ditch the generic outline slide)

“首先我将介绍背景，然后是方法，接着是实验，最后是结论”——这种目录页毫无营养，只会让听众瞬间走神。

---

### 开门见山亮出核心成果 (Tease the core result early)

直接向听众剧透你的最大突破，给他们一个继续听完全场 30 分钟演讲的强烈理由！
