# 如何在线上虚拟学术会议中进行学术社交？ (How to network in a virtual conference?)

> 原始推文：[https://twitter.com/jbhuang0604/status/1446692346800873477](https://twitter.com/jbhuang0604/status/1446692346800873477)

---

如何在线上虚拟学术会议中进行学术社交？

线上会议缺乏面对面走廊偶遇的自然契机，但只要方法得当，线上交流同样能够结识良师益友。  
分享线上会议的社交技巧。🧵

---

### 1. 积极在 Q&A 聊天区提问 (Engage in chat)

在口头报告或 Panel 讨论期间，在聊天框中提出具体且有深度的问题，署上自己的姓名和机构。  
优秀的提问能让讲者和全场参会者立即记住你。

---

### 2. 主动在 Gather.town 或虚拟展厅中驻足互动

在虚拟会议平台的虚拟展厅中主动与站在展板旁的作者开启文字或音视频对话。

---

### 3. 会议期间在 Twitter/X 上同步讨论并 @ 作者

在社交媒体上分享你对某篇报告的思考或见解，并 @ 演讲作者。这种公开的学术点赞常常能直接促成深入私信交流。
